## The entry

> **Human Ctrl-Z for Other People's Mistakes**

A real-sounding job with one gloriously specific twist: a human being whose entire job is to undo other people's mistakes — like the Ctrl-Z key, but a person.

## How it works

`main.ts` writes the single job title (40 characters, no trailing newline) to `/output/entry.txt`. Run it with Node 22+:

```sh
node main.ts
```
